Mesin yang dipakai

Query dijalankan oleh SQLite di dalam browser (SQL.js), bukan oleh server MySQL. SELECT, WHERE, JOIN, GROUP BY, subquery, INSERT, UPDATE, dan DELETE bekerja dengan cara yang sama seperti di MySQL.

Perbedaan yang sering ditemui

  • SHOW TABLES dan DESCRIBE tidak ada. Lihat tab Skema tabel.
  • CONCAT(a, b) ditulis a || b.
  • AUTO_INCREMENT menjadi AUTOINCREMENT.
  • Fungsi tanggal seperti NOW() dan DATEDIFF() tidak tersedia.

Tentang data Anda

  • Perubahan data (INSERT, UPDATE, DELETE) hanya ada di tab ini. Memuat ulang halaman atau menekan Reset database mengembalikan data awal.
  • Penilaian selalu memakai data awal, bukan data hasil perubahan Anda.
  • Daftar soal yang sudah selesai disimpan di browser ini.
